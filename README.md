# jonathandigiorgio.com

Personal portfolio site. Plain HTML, CSS and JS, generated by a small Python script.

## Run locally

```
pip install pillow
python build.py
python -m http.server 8000
```

Then open http://localhost:8000.

## Edit

- `content.py` has all the copy, the project list and the image definitions.
- `build.py` has the page templates and the image pipeline (sources in `_src/`, output in `assets/img/`).
- `assets/site.css` and `assets/site.js` are hand-written.
- `DESIGN-NOTES.md` lists the AI-site tells this design avoids.

Run `python build.py` after any change and commit the generated files. Netlify serves the repo root as-is.
